# ✏️ Pencil Flight (مداد پرنده)

یک بازی آرکید اندرویدی ساخته‌شده با **Flutter** برای پروژه‌ی مدرسه.
پرنده‌ی قرمز رو با لمس صفحه بپر تا از بین مدادها رد بشی و امتیاز بگیری!

## ویژگی‌ها
- کنترل با یک لمس
- افزایش تدریجی سختی
- ذخیره‌ی رکورد روی گوشی
- گرافیک کاملاً کدنویسی‌شده (بدون فایل تصویری)

## طرز اجرا
```bash
flutter pub get
flutter run
```

## ساخت APK
```bash
flutter build apk --release
```
